# Introduction discussion — drop-in template

A guided tour of Chippy as a Chippy discussion: 46 open tasks, one per feature,
each with an annotated screenshot. The essentials are priority HI (tasks 01–10),
the important features MI (11–30), the rest LO (31–46). Task 01 sits at the top
of the history — work top to bottom and set each task to DONE as you master it.
Task 03 creates a practice discussion, "Chippy Learning" (tag: training) — it
appears in the sidebar of every following screenshot, and it is the place to
repeat each exercise yourself.

## Install

Copy **both** of these into your Chippy data folder (next to your other
discussion .md files):

    Introduction.md
    Introduction/          (the screenshot folder, 46 .jpg files)

Then open the folder in Chippy (or use the ↻ reload-folder button next to +
if it is already open). The navigation reconciler picks the new discussion up
automatically — no other setup. Archive or delete the discussion whenever the
tour has served its purpose.

Note: Chippy ≥ v3.2.0-dev.122 reads the file regardless of line endings; the
images are referenced relative to the data folder, so keep the folder name
`Introduction` unchanged.
