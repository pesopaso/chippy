# Introduction

## Preparation

Welcome to Chippy! This discussion is a guided tour: every open task explains one feature and shows where to find it on a screenshot. Work top to bottom — the numbering starts with the essentials (high priority), then the important features (medium), then the rest (low). Set each task to DONE as you master it; your progress shows up on the Kanban board and the Activity page, which is itself a first exercise.
